# Criterios de clasificación de un recurso académico

Estos criterios permitirán clasificar cualquier recurso que se agregue al
catálogo (libro, sitio web, video, artículo o herramienta de software).

1. **Tipo**: naturaleza del recurso (libro, sitio web, video, artículo,
   herramienta de software).
2. **Tema**: área de conocimiento a la que pertenece el recurso (por
   ejemplo, desarrollo web, bases de datos, buenas prácticas).
3. **Nivel**: grado de dificultad o público objetivo (básico, intermedio,
   avanzado).
4. **Autor o fuente**: persona, organización o plataforma que produjo el
   recurso.
